Рабочая папка-это папка на компьютере, где лежит проект и скрытая папка .git — там хранится вся история.



Индекс-это промежуточная зона. Файлы попадают туда после git add, но до git commit.



Коммит-сохранённая точка в истории. У неё есть автор, дата, сообщение



Git — программа на компьютере, хранит историю локально.



GitHub — сайт, куда эту историю можно залить и делиться с другими.



git status — показывает, что изменено, что в индексе, что не отслеживается.

git diff — сравнивает рабочую папку с последним коммитом (что я поменяла, но ещё не добавила).

git diff --staged — сравнивает индекс с последним коммитом (что я уже добавила, но ещё не сохранила).
